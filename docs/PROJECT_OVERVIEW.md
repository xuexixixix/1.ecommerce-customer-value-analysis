# 面试讲解提纲

## 业务问题

如何从交易明细中识别高价值客户、流失风险客户和新进高潜客户，并用历史行为辅助未来消费预测？

## 数据处理

1. 删除 `CustomerID` 缺失记录。
2. 删除数量和单价小于等于 0 的退货或异常记录。
3. 构造 `TotalAmount = Quantity * UnitPrice`。
4. 将数据拆分为客户、订单和订单明细三张表，使用主键/外键维护关系。

## 分析方法

- 描述性分析：国家销售额排名和交易明细金额分布。
- 假设检验：使用 Welch 独立样本 T 检验比较英国与海外交易明细的平均金额；当前实现不是按订单汇总的客单价检验。
- RFM 分群：按 Recency、Frequency、Monetary 五分位打分，并映射到业务标签。
- 预测建模：基于 Recency、Frequency、购买数量、历史消费金额和客单价，预测未来 90 天消费金额；对右偏特征和目标变量使用 `log1p`，用 OOT 时间窗口验证泛化能力。

## 实际结果

- 原始数据：541,909 行、8 列；清洗后：397,884 行、9 列。
- 清洗后销售额最高的国家为英国，销售额约 £7,308,391.55；前五名还包括 Netherlands、EIRE、Germany 和 France。
- Welch T 检验显示，英国与海外交易明细平均金额分别为 £20.63 和 £36.80，p-value = 1.1938e-121，差异具有统计显著性。该结果不等同于订单客单价差异。
- RFM 分群得到 999 个核心高价值客户、211 个高频流失预警客户、233 个新进高潜客户和 2,895 个一般维持客户。
- 线性回归 OOT 验证得到 R² = 0.1689，原始金额空间 MAE = £873.52。该模型是可解释的基线模型，预测能力仍有提升空间。

## 面试时可说明的局限

- 当前模型为线性回归基线，后续可比较 LightGBM、随机森林或 Gamma/Tweedie 类模型。
- RFM 分群规则是业务启发式规则，需要结合营销触达结果验证分群价值。
- 当前项目未包含原始数据和线上部署，复现时需要使用同字段的数据集并重新刷新 PBIX。
